HRMIS TopUp & Leave Management

Web Developer (Backend + Frontend) · Apr 2025 – Dec 2025 · PT. Neuronworks Indonesia

Problem

Leave requests and credit top-ups were handled manually via spreadsheets. The process was slow, error-prone, and HR had no real-time visibility into what was pending or approved.

My Contribution

  • Designed and built the TopUp module backend: create request, admin approval flow, balance tracking, and transaction history (NestJS).
  • Built the Leave module end-to-end: submission, multi-level approval workflow, quota tracking, and status visibility for employees.
  • Developed Vue.js pages for both modules: forms, status dashboards, and admin review panels.
  • Implemented RBAC via NestJS Guards to separate employee, manager, and admin permissions cleanly.
  • Collaborated with QA for ITQA and resolved all security findings from Penetration Testing.

Solution Approach

Database-level state machine per request (PENDING → APPROVED / REJECTED). PostgreSQL transactions for atomic balance updates no race conditions on concurrent approvals. Redis session caching to cut down JWT validation overhead.

HR Anomaly Detection Dashboard

Undergraduate Thesis · Universitas Pendidikan Indonesia · 2026

Background

This thesis addresses a real HR problem: how do you automatically detect employees with abnormal performance profiles, and more importantly, explain why a profile is flagged not just return an "anomaly" label with no context?

What I Built

  • Isolation Forest (unsupervised) as the primary anomaly detection model no labels needed.
  • XGBoost Surrogate Model for interpretability retrained on pseudo-labels from Isolation Forest.
  • TreeSHAP to break down each attribute's contribution per individual employee.
  • React dashboard with SHAP waterfall charts, scatter plots, and boxplot distributions.
  • Comparative context panel: individual vs. company average across salary, career, and wellbeing dimensions.
  • Real-time prediction form: input new employee data and get an anomaly score instantly from the ML engine.
